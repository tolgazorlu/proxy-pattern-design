# Proxy Pattern Design

Java examples of the Proxy design pattern, including a protection-proxy variant with user access control.

## About
A small study repo demonstrating the Proxy structural design pattern in Java, with notes in Turkish (PDF). Built January 2021.

## Features
- `ProxyPatternExample.java`: baseline Subject/Proxy/RealSubject implementation
- `ProxyPatternAlternate.java`: an alternate take on the same pattern
- `ModifiedProxyPatternExample.java`: a protection proxy that checks the current user against a registered-users list before delegating work
- `Proxy Tasarım Deseni.pdf`: accompanying notes (Turkish)

## Tech stack
- Java

## Getting started
```bash
javac ProxyPatternExample.java
java ProxyPatternExample
```
Each `.java` file is self-contained and can be compiled/run the same way.
